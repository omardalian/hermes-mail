Hermes Mail – Privacy Policy

Last updated: November 8, 2026

Who uses it

Hermes Mail is a personal tool. Its only user is its developer, who uses it with their own Gmail accounts. It is not offered to the public.

What data it accesses

With the owner's permission, Hermes Mail uses the Gmail API to read message headers and content and to change labels (for example, adding a label or marking a message as read). It does not send, forward or permanently delete email.

How the data is used and stored

  • Messages are processed on the owner's own computer, by software running on that computer.
  • Message content is stored only on that computer, and the text of messages is deleted after 30 days.
  • The only information that leaves the computer is short notifications sent to the owner (for example, "Electric bill due Nov 20"), with sensitive details removed.

Sharing

Gmail data is not sold, shared with third parties, used for advertising, or used to train AI models. Nobody other than the owner can access it.

Google API Services

Hermes Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored data is then deleted.
